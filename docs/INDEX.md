# Igloo Shell Manual

`docs/` is the operator and shell manual for `igloo-shell`.

## Read First

- `GUIDE.md`: first local bootstrap, managed profile import, relay startup, and shell commands.
- `CONFIGURATION.md`: developer-oriented path-based runtime config shape generated by `dev keygen`.
- `OPERATIONS.md`: day-2 shell workflows, runtime checks, and e2e commands.
- `TESTING.md`: managed-profile runtime smoke, daemon/TUI checks, and soak coverage.
- `V2-SHELL-SPEC.md`: authoritative V2 CLI/TUI product and implementation specification.
- `PROFILE-AND-VAULT-ARCHITECTURE.md`: implementation architecture for shell-managed profiles, vaults, and daemon bootstrap.

## Context

- `igloo-shell` owns the CLI, TUI, relay, keygen, invite assembly/acceptance, and shell-owned runtime e2e flows.
- `bifrost-rs` remains the signer, router, bridge, codec, and host core behind those workflows.
- Cross-repo architecture lives at `../../../docs/INDEX.md`.
