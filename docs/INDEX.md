# Igloo Shell Manual

`docs/` is the operator and shell manual for `igloo-shell`.

## Read First

- `GUIDE.md`: first local bootstrap, managed profile import, relay client setup, and shell commands.
- `CONFIGURATION.md`: developer-oriented path-based runtime config shape generated by `bifrost-devtools keygen`.
- `OPERATIONS.md`: day-2 shell workflows, runtime checks, and developer e2e commands.
- `TESTING.md`: managed-profile runtime smoke, daemon checks, and soak coverage.
- `V2-SHELL-SPEC.md`: authoritative V2 CLI and daemon product specification.
- `PROFILE-AND-VAULT-ARCHITECTURE.md`: implementation architecture for shell-managed profiles, vaults, and daemon bootstrap.

## Context

- `igloo-shell` owns the operator CLI, managed-profile state, and package/onboarding workflows.
- `bifrost-rs` owns the signer, router, bridge, codec, host core, and `bifrost-devtools` developer relay/keygen/e2e tooling.
- Cross-repo architecture lives at `../../../docs/INDEX.md`.
